# Project Context: Sub-sampled Fiedler Vector Experiments

## Project Overview

This project implements a modular framework for evaluating how well averaged Fiedler vectors from subsampled data preserve the partition quality of the Spectral Top-Down Recovery (STDR) algorithm for phylogenetic tree reconstruction.

### Research Question

**Core Question**: "Does averaging aligned Fiedler vectors computed from subsampled similarity matrices (S) produce the same bipartition as a Fiedler vector computed from the full similarity matrix (M) when both are evaluated using STDR's partition algorithm?"

**Why This Matters**:
- Subsampling reduces computational cost but introduces noise
- If averaged subsampled Fiedler vectors preserve STDR partition quality, we can use cheaper computation without sacrificing accuracy
- This bridges theoretical spectral methods with practical constraints

### Scientific Context

**STDR Algorithm** (Spectral Top-Down Recovery):
1. Computes similarity matrix from sequence data
2. Builds graph Laplacian L = D - S
3. Computes Fiedler vector (2nd smallest eigenvector of L)
4. Uses gap-based thresholding to find optimal bipartition
5. Recursively applies to subtrees

**Our Extension**:
- Instead of computing Fiedler from full M, we:
  1. Subsample M → S (randomly zero out entries with probability 1-p, scale by 1/p)
  2. Compute Fiedler from each S across K bootstrap iterations
  3. Align all Fiedler vectors (handle sign ambiguity)
  4. Average to get consensus Fiedler vector
  5. Compare partition quality using multiple metrics

## Key Architectural Decisions

### 1. Streaming S Average (Welford's Algorithm)

**Decision**: Don't store all K bootstrap S matrices; maintain running average online.

**Why**:
- Memory savings: ~12.8 GB for n=4000, K=100
- Numerically stable (avoids catastrophic cancellation)
- Only stores single S_avg matrix (~128 MB for n=4000)

**Implementation** (`bootstrap_sweep.py:200-234`):
```python
S_avg = None
n_bootstrap_collected = 0

for i in range(cfg.bootstrap_reps):
    S = _subsample_matrix_entries(M, p, seed=cfg.seed + i)

    if S_avg is None:
        S_avg = S.copy()
        n_bootstrap_collected = 1
    else:
        n_bootstrap_collected += 1
        S_avg += (S - S_avg) / n_bootstrap_collected  # Welford update
```

**Key Insight**: This is NOT Welford's variance formula (which uses `(x - old_mean) * (x - new_mean)`). This is Welford's **mean** formula: `new_mean = old_mean + (x - old_mean) / n`.

### 2. Single Partition Agreement Function

**Decision**: One `compute_partition_agreement(fiedler_full, fiedler_avg, similarity_for_full, similarity_for_avg)` function called twice, not two separate functions.

**Why**:
- Reduces code duplication
- Makes it clear both metrics use identical partition logic
- Only difference is which similarity matrices are passed

**Usage**:
```python
# Ideal scenario: both use M
partition_agr_M = compute_partition_agreement(fiedler_ref, v_avg, M, M, num_gaps, min_split)

# Realistic scenario: reference uses M, test uses S_avg
partition_agr_S = compute_partition_agreement(fiedler_ref, v_avg, M, S_avg, num_gaps, min_split)
```

### 3. Strict Fiedler Computer Function

**Decision**: `compute_fiedler_from_similarity(S)` requires S to be passed, fails fast if None.

**Why**:
- Avoids redundant computation (S already computed in bootstrap loop)
- Makes data flow explicit: S → Fiedler, not sequences → S → Fiedler
- Fail-fast philosophy prevents silent bugs

**Before** (old code):
```python
f_est = cfg.fiedler_method(M, None, None, p=p, seed=seed)  # Recomputed S internally
```

**After** (new code):
```python
S = _subsample_matrix_entries(M, p, seed=seed)
f_est = cfg.fiedler_method(S)  # S passed directly
```

### 4. Three Partitions, Two Agreement Scores

**Decision**: Compute 3 partitions but report only 2 agreement scores.

**Why**:
- **Partition 1** (reference): `partition_taxa(fiedler_full, M)` - ground truth
- **Partition 2** (ideal test): `partition_taxa(fiedler_avg, M)` - tests vector quality in isolation
- **Partition 3** (realistic test): `partition_taxa(fiedler_avg, S_avg)` - realistic STDR performance

**Agreement scores**:
- `partition_agreement_M`: Partition 1 vs Partition 2 (ideal scenario)
- `partition_agreement_S`: Partition 1 vs Partition 3 (realistic scenario)

### 5. Full Backward Compatibility

**Decision**: Keep legacy `sign_agreement` metric and old function interfaces.

**Why**:
- Allows comparison with historical results
- Gradual migration path
- Supports old JSON formats automatically

## Code Patterns and Best Practices

### Pattern 1: Fail-Fast Error Handling

**When computing metrics fails, log warning and return NaN**:
```python
try:
    partition_agr_M = compute_partition_agreement(...)
except Exception as e:
    log_warning('bootstrap', f"partition_agreement (M) failed: {e}")
    partition_agr_M = float('nan')
```

**Why**: One metric failure shouldn't crash entire experiment. NaN propagates gracefully through analysis pipeline.

### Pattern 2: Normalized Vector Operations

**Always normalize before computing dot products**:
```python
def _normalize_vector(v: np.ndarray) -> np.ndarray:
    norm = np.linalg.norm(v)
    if norm < 1e-12:
        raise ValueError(f"Vector has zero or near-zero norm: {norm}")
    return v / norm
```

**Why**: Prevents numerical instability and ensures dot products measure angle, not magnitude.

### Pattern 3: Partition Orientation Handling

**Both A|B and B|A represent same partition**:
```python
matches_direct = np.sum(partition_full == partition_avg)
matches_flipped = np.sum(partition_full != partition_avg)
max_matches = max(matches_direct, matches_flipped)
agreement = 100.0 * max_matches / len(partition_full)
```

**Why**: Fiedler vectors have sign ambiguity; partitions should be orientation-invariant.

### Pattern 4: Progressive Disclosure in Progress Bars

**Show increasingly specific information as computation progresses**:
```python
# Outer loop: high-level configuration
grid_pbar.set_description(f"Config {combo_idx}/{total}: n={n_taxa}, L={seq_len}")

# Inner loop: current p-value and metrics
p_pbar.set_description(f"p={p:.2e}")
p_pbar.set_postfix({'sign_agreement': f'{sign_agreement:.1f}%'})
```

### Pattern 5: Incremental Saving

**Save results after each parameter combination in sweeps**:
```python
for n_taxa, seq_len in product(taxa_values, seq_len_values):
    fiedler_ref, sig, ... = sweep_for_params(...)
    all_results[(n_taxa, seq_len)] = sig

    # Save incrementally (don't wait until end)
    save_grid_results(run_dir, p_values, all_results, all_metrics)
```

**Why**: Long experiments can crash; incremental saves allow partial recovery.

## Key Concepts and Terminology

### Fiedler Vector
- 2nd smallest eigenvector of graph Laplacian L = D - S
- Used for spectral graph bipartitioning
- Has **sign ambiguity**: v and -v are both valid eigenvectors
- Magnitude of components indicates "distance" from partition boundary

### Similarity Matrix
- **M**: Full similarity matrix from complete sequence data (n×n)
- **S**: Subsampled similarity, S[i,j] = M[i,j]/p with probability p, else 0
- **S_avg**: Average of K subsampled matrices (streaming computation)
- **L**: Laplacian = D - S, where D is degree matrix

### Partition Taxa Algorithm
From `spectraltree.spectral_tree_reconstruction.partition_taxa`:
1. Sort Fiedler vector to find `num_gaps` largest gaps
2. For each gap, create candidate partition threshold
3. For each threshold, compute partition and evaluate SVD quality
4. Choose threshold that minimizes σ₂ (second singular value) of within-partition similarities
5. Return binary partition: 0/1 array indicating which side of partition each taxon belongs to

**Key parameters**:
- `num_gaps`: Number of gap-based thresholds to try (default=1)
- `min_split`: Minimum partition size to consider valid (default=1)

### Metrics

#### sign_agreement (legacy)
- Percentage of taxa where sign(fiedler_full) == sign(fiedler_avg)
- Range: 0-100%
- Simple but doesn't reflect actual STDR behavior

#### partition_agreement_M (ideal scenario)
- Both partitions use M (full similarity)
- Tests: "Does averaged Fiedler preserve partition quality?"
- Isolates vector quality from matrix quality

#### partition_agreement_S (realistic scenario)
- Reference uses M, test uses S_avg
- Tests: "How does STDR perform with our averaged subsampled Fiedler?"
- Realistic end-to-end metric

#### dot_product (vector alignment)
- |⟨u_norm, v_norm⟩| between normalized vectors
- Range: 0-1 (1 = perfect alignment)
- Continuous measure of similarity

### Bootstrap Alignment
1. Compute K Fiedler vectors from subsampled S matrices
2. Align each to reference by maximizing dot product
3. Average aligned vectors to get consensus
4. Normalization ensures equal weighting

## Common Gotchas and Debugging

### Issue 1: Progress Bars Overlapping
**Symptom**: Multiple progress bars overwrite each other or create visual glitches.

**Cause**: Nested progress bars without proper `position` parameter.

**Fix**:
```python
outer_pbar = create_progress_bar(..., position=0, leave=True)
inner_pbar = create_progress_bar(..., position=1, leave=False)
```

### Issue 2: Memory Explosion in Grid Search
**Symptom**: Memory usage grows linearly with number of parameter combinations.

**Cause**: Not clearing similarity cache between runs.

**Fix**: Call `clear_similarity_cache()` after each parameter combination:
```python
for n_taxa, seq_len in product(taxa_values, seq_len_values):
    run_experiment(...)
    clear_similarity_cache()  # Essential!
```

### Issue 3: NaN in Partition Agreement
**Symptom**: `partition_agreement_M` or `partition_agreement_S` returns NaN.

**Possible causes**:
1. **S_avg is None**: Check that p < 1.0 (p=1.0 doesn't enter bootstrap loop)
2. **partition_taxa raised exception**: Check log warnings
3. **Degenerate Fiedler vector**: All zeros or uniform values (norm < 1e-12)

**Debug**:
```python
# Check S_avg
if S_avg is None:
    log_warning('bootstrap', f"S_avg is None for p={p}")

# Check vector normalization
norm = np.linalg.norm(v_avg)
if norm < 1e-12:
    log_warning('bootstrap', f"Degenerate average vector: norm={norm}")
```

### Issue 4: Sign Agreement vs Partition Agreement Mismatch
**Symptom**: High sign_agreement but low partition_agreement_M.

**Why this is normal**:
- Sign agreement is point-wise comparison
- Partition agreement depends on threshold placement
- Small errors near partition boundary can flip entire partition

**Example**: Fiedler vector `[-2, -1, 0.1, 1, 2]` vs `[-2, -1, -0.1, 1, 2]`
- Sign agreement: 80% (4/5 match)
- Partition agreement: 0% (threshold at 0 gives opposite partitions)

### Issue 5: File Modified by Linter
**Symptom**: Edit tool fails with "File has been modified since read".

**Cause**: Auto-formatter (black, autopep8) ran after you read file.

**Fix**: Re-read file before editing:
```python
Read(file_path=path)
Edit(file_path=path, old_string=..., new_string=...)
```

### Issue 6: Experiment Takes Too Long
**Symptom**: Grid search with many parameter combinations runs for hours.

**Solutions**:
1. **Reduce bootstrap_reps**: 100 → 50 or 25 for initial testing
2. **Reduce p_values range**: Use fewer, more spaced values
3. **Use incremental saves**: Results saved after each combination
4. **Run subset of grid**: Comment out some taxa_values or sequence_length_values
5. **Profile bottlenecks**: Most time in eigenvalue computation, not bootstrap alignment

## Testing and Validation

### Expected Behavior at Different p-values

**p → 0** (heavy subsampling):
- `sign_agreement`: ~50% (random alignment)
- `partition_agreement_M`: ~50% (random partition)
- `partition_agreement_S`: ~50% (random partition)
- `dot_product`: ~0.0 (orthogonal vectors)

**p ~ 0.01-0.1** (moderate subsampling):
- All metrics improve as p increases
- `partition_agreement_S` < `partition_agreement_M` (S_avg is noisier than M)
- Sharp transition in partition agreement (threshold effects)

**p → 1.0** (minimal subsampling):
- `sign_agreement`: ~100%
- `partition_agreement_M`: ~100%
- `partition_agreement_S`: ~100%
- `dot_product`: ~1.0

### Sanity Checks

**Check 1**: Partition agreement should be ≥ sign agreement
- If sign agreement is X%, partition can't disagree on more than (100-X)% of taxa
- If violated, check for sign alignment bugs

**Check 2**: partition_agreement_S ≤ partition_agreement_M
- S_avg is noisier than M, so using S_avg should perform worse or equal
- If violated, check for incorrect matrix assignment

**Check 3**: For p=1.0, all metrics should be ~100%
- Subsampling with p=1.0 means S=M (no zeroing)
- If not ~100%, check Fiedler computation or alignment

## Mathematical Background

### Graph Laplacian
Given similarity matrix S (n×n, symmetric, non-negative):
- Degree matrix: D = diag(S·1), where 1 is all-ones vector
- Laplacian: L = D - S
- Properties:
  - L is symmetric positive semi-definite
  - Smallest eigenvalue is 0 (eigenvector = 1)
  - 2nd smallest eigenvalue λ₂ is called algebraic connectivity
  - Fiedler vector is eigenvector for λ₂

### Fiedler Vector for Bipartitioning
- Sort vertices by Fiedler vector values
- Find threshold τ that splits into A = {i: v[i] < τ}, B = {i: v[i] ≥ τ}
- Minimizes normalized cut: `Ncut(A,B) = cut(A,B)/vol(A) + cut(A,B)/vol(B)`
- STDR enhances this with gap-based search and SVD quality scoring

### Subsampling Model
- S[i,j] = M[i,j]/p with probability p, else 0
- E[S] = M (unbiased estimator)
- Var[S[i,j]] = M[i,j]²(1-p)/p
- As p → 0, variance → ∞, eigenvalue estimates degrade

### Welford's Algorithm
For streaming mean computation:
```
μ₀ = x₁
For n = 2, 3, ..., N:
    μₙ = μₙ₋₁ + (xₙ - μₙ₋₁) / n
```

**Why it's stable**:
- Avoids catastrophic cancellation from (Σx)/n
- Each update is small correction to previous mean
- Works well even with large dynamic range

**Extension to matrices**: Apply element-wise:
```
S_avg[i,j] = S_avg[i,j] + (S_new[i,j] - S_avg[i,j]) / n_collected
```

## Performance Considerations

### Computational Bottlenecks
1. **Eigenvalue computation**: O(n³) for dense matrices
   - Dominates for large n (n > 1000)
   - Use sparse solvers if S is very sparse (p << 1)
2. **Bootstrap iterations**: Linear in K (bootstrap_reps)
3. **Partition search**: O(num_gaps × n log n)
   - Sorting + SVD for each threshold

### Memory Bottlenecks
1. **Similarity matrices**: O(n²) per matrix
   - Streaming S_avg eliminates O(K×n²) storage
2. **Aligned vectors**: O(K×n)
   - Necessary for final averaging
3. **Grid search**: O(#combinations × n²)
   - Mitigated by `clear_similarity_cache()` between runs

### Optimization Tips
- **Reduce bootstrap_reps** for initial experiments (100 → 25)
- **Use sparse matrices** if p < 0.1 (not currently implemented)
- **Parallelize p-values**: Independent, could use multiprocessing (not implemented)
- **Cache M**: Don't recompute for same (n_taxa, seq_len, mutation_rate)

## Version History and Evolution

### Original Implementation
- Only `sign_agreement` metric
- Stored all K bootstrap S matrices
- `random_entries_fiedler` computed S internally

- 4 metrics: sign_agreement, partition_agreement_M, partition_agreement_S, dot_product
- Streaming S_avg (Welford's algorithm)
- Strict `compute_fiedler_from_similarity(S)` requiring explicit S

### Design Rationale for Changes
1. **Streaming S_avg**: Memory constraints for large-scale experiments
2. **Partition metrics**: Reflect actual STDR behavior, not proxy metric
3. **Dual scenarios**: Ideal (M,M) vs Realistic (M,S_avg) to understand both vector quality and end-to-end performance
4. **Strict Fiedler function**: Avoid redundant computation, make data flow explicit
